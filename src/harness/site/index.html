Stage 3: Red-Team Security & Pentest Agent Findings

The Pentest Agent attacks the selected project across 8 adversarial vectors (ATK-01 SQL/FTS5 injection, ATK-02 RBAC escalation, ATK-03 SHA-256 digest forgery, ATK-04 1,000-user SQLite lock contention, ATK-05 payload DoS, ATK-06 XSS/control-byte injection, ATK-07 clock skew, and ATK-08 HTTP security headers).

Stage 4: Point-by-Point Pentest Agent ↔ Improvement Agent Remediation Transcript

Every weakness uncovered by the Pentest Agent is handed to the Improvement Agent, which implements the architectural fix following TDD and logs the exact code target and regression test.

Stage 5: 1,000-Virtual-User Concurrency & Multi-Step Flow Simulation

Simulates 1,000 concurrent users (3,000 total workflow step requests) across 5 realistic personas, comparing system behavior Before Hardening vs. After Improvement Agent Hardening.
